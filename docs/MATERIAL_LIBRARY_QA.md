# 素材库映射、缩略图与保存语义核查

日期：2026-11-05。源码修改及静态核查记录；尚未编译、尚未运行验证，不代表生产 EXE 已通过交互验收。

## 已确认行为

- `styles/library.json` 是唯一持久化素材映射。`config/settings.json` 使用版本 3，仅按 `style_name` 引用选择；兼容版本 1/2，下一次保存配置时迁移，已有图片不改名。
- 新导入保持源文件名，磁盘或映射路径重名时按 `name_1.png`、`name_2.png` 递增，独占复制，不覆盖文件。显示名称独立命名，仍保留原有命名校验。
- 进入或再次点击素材库选项卡、点击“刷新”均后台重读映射与目录，登记未映射的有效图片，清理明确不存在的项。非递归扫描，访问失败保留记录；缩略图解码完成后再次检查文件，涵盖刷新中途删除。
- 列表单击及键盘选择只更新窗口预览，正式提示使用最近保存的配置。素材页“保存配置”提交整个草稿；取消恢复进入前的选择，保留已完成的素材登记和刷新结果。
- 正式素材被确认删除，即时恢复默认绿色光圈、36 DIP 半径、7 DIP 线宽、90% 不透明度、3 秒保持及默认自定义外观参数，保留主题、语言及快捷键。保存失败仍清除运行时旧缓存，并报告持久化失败。
- 列表每项使用真实等比例首帧缩略图，缓存最长边 96 像素；GIF 首帧即使零延时也单独用于缩略图。素材大预览完整适配现有框、不裁切，GIF 沿用完整解码、帧合成和循环播放。

## 控件来源及原生适配

本次为 **Ant Design 规范的 Win32 原生适配**，不运行 React 组件。来源链从官方总览左侧分类进入组件页面，并读取各页面真实的 LLMs.md 链接正文；采用以下现有变体：

| 来源链 | 所选形式及文档 | 现有控件 → 原生显示位置 → 业务入口 |
| --- | --- | --- |
| [总览](https://ant.design/components/overview-cn/) → 数据展示 → [List](https://ant.design/components/list-cn/) → 基本横排 `List.Item.Meta` | [List LLMs.md](https://ant.design/components/list-cn.md)，`itemLayout=horizontal`、无额外外框、名称与描述、行分隔 | 原“当前选择”卡片内容 → `DrawMaterialListItem`、原生单选 LISTBOX → `BeginSelectStyle` / `FinishImport` |
| 总览 → 数据展示 → [Image](https://ant.design/components/image-cn/) → 基本图片、关闭弹层预览 | [Image LLMs.md](https://ant.design/components/image-cn.md)，缩略图 `preview=false` | 原固定光圈示意 → GDI+ 真实图片；原大预览区域 → `DrawMaterialPreview` → `LoadMappedStyle` / 现有 WIC 解码 |
| 总览 → 通用 → [Button](https://ant.design/components/button-cn/) → 默认次按钮及现有主按钮 | [Button LLMs.md](https://ant.design/components/button-cn.md)，普通“刷新”、原主操作“导入素材”及“保存配置” | 新刷新按钮与原按钮绘制入口 → `MaterialsProc` → `BeginLibraryRefresh` / `BeginImport` / `CloseMaterials(true)` |

列表保留官方横向结构：左侧 48 DIP 图片，16 DIP 图文间隔，右侧上方名称、下方类型；上下各 12 DIP，行高 72 DIP。仅将图片宽高调整至现有卡片适用尺寸，按 DPI 等比例换算，复用项目主题与字体。原生列表负责单选、方向键、滚轮、焦点和禁用语义；无网页图片弹层或工具栏。当前 List 官方文档标记了后继 Listy；本次采用已核实的 List 横排预设结构，不涉及运行时 Web 组件升级。

显示层仅承担绘制和事件转接。单一映射、刷新、文件命名及提交时机是本次用户另行确认的业务修改，分别实现于 `portable_settings.cc`、`image_asset.cc`、`settings_window.cc`，未因控件适配重写钩子、快捷键或提示层逻辑。
