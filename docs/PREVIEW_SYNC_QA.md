# 图标、文字与滑块实时预览修复

2026-11-05。用户确认复用正式图标、保留英文副标题、修复文字遮挡和高 DPI 错位，并要求拖动滑块时上方示例同步更新。保留四套主题与现有工作台布局。

## 原因与修改

- 侧栏原先独立手绘四顶点指针，未复用程序图标；英文副标题区域只有 83 DIP，而本机 9pt 字体测量约需 97 DIP。现改用内嵌 `IDI_APP_ICON` 的共享资源句柄，按目标 DPI 绘制；副标题移至 131×18 DIP 的独立行。共享图标句柄由 Windows 管理。
- 预览标题原范围为 x=17–100 DIP，状态胶囊为 x=74–120 DIP，存在交叠；现分别为 x=17–89、101–155 DIP，并以中文「同步」显示状态。
- 舞台宽高已经是物理像素，原右上说明及空素材说明却再次将宽高送入 DIP 换算。现只缩放边距及行高。空素材说明显示时不绘制示例箭头。
- 原侧栏品牌固定绘制，但导航按钮随工作区滚动，且正文与子控件没有侧栏裁剪。现导航固定，正文绘制裁剪在侧栏右侧；工作区控件（含素材页容器）只在侵入侧栏时设置窗口区域，返回正常位置后移除区域。区域设置成功后所有权交给 Windows，失败时释放临时区域。键盘自动滚入可见区也使用侧栏右边界。
- 滑块事件链原已更新草稿并失效预览，但半径绘制为 `min(radius_dip * 1.9 * dpi, min(width, height) * 0.30)`；232 DIP 高的舞台在约 36.6 DIP 以后大小固定，线宽还受最小值和半径比例截断。
- 现按舞台安全区及完整允许范围求固定比例：内置模式预留最大半径 100 DIP 加最大半线宽 10 DIP，自定义素材预留最大半尺寸 256 DIP。半径、线宽使用同一比例；图片/GIF 保留宽高比和不透明度，不再随当前值改变缩放比例或钳制尺寸。
- 滑块先写入对应的有效草稿值，再同步其他合法输入；即使其他输入框暂时留空或越界，对应滑块仍更新。半径缩小时仍归一化光圈线宽。最后仅对上方示例调用 `UpdateWindow`，使连续拖动消息期间也处理预览绘制。

## 静态核查

- 核对 `WM_HSCROLL → HandleSlider → PreviewDraft → RefreshPreview` 及即时绘制调用，覆盖半径、线宽、不透明度三个滑块；保存仍须通过全部输入校验，取消仍恢复原设置。
- 使用本机 System.Drawing 和 Microsoft YaHei UI，按源码字体像素高度测量侧栏标题、副标题、预览标题、同步状态及右侧说明，覆盖 96/120/144/192 DPI 共 20 项，均能放入各自区域。此测量不能替代真实 GDI 绘制验收。
- 资源文件含 16/20/24/32/40/48/64/128/256 像素图标，直接使用已内嵌资源，不引入外部运行文件。
- 几何检查覆盖 96/120/144/192 DPI 及 820/900/1200 DIP 主窗口宽度共 12 组布局；核对 4104 次半径取值、22212 个合法光圈半径/线宽组合、8964 个正方/横向/纵向素材尺寸，以及 1584 次不透明度取值。半径、线宽、不透明度映射均持续变化，图形边界位于标题和底部信息条之间。
- 滚动裁剪与键盘滚入的几何核查覆盖四种 DPI、520/640/800/820/900 DIP 视口及不同滚动位置，共 240 项，裁剪后的工作区不侵入侧栏；正常位置撤销裁剪。另只读复核窗口区域的所有权、重复区域短路及布局重入保护。
- C++ 修改范围使用根目录 Google 风格配置进行 clang-format 检查。未改动设置模型、持久化字段、钩子线程或系统指针操作。

## 用户手动构建与验收

尚未编译、尚未运行验证。未启动现有 EXE 或安装包，静态测量与几何检查不能证明真实 Win32 拖动刷新、DPI 切换和绘制表现已通过。

1. 在项目根目录手动执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1`，或双击 `build.cmd`。
2. 在四套主题和 100%/125%/150%/200% 缩放下检查侧栏：正式图标清晰，中文标题与完整 `MOUSE CURSOR` 均可见；预览标题、同步状态及右侧说明互不遮挡。跨不同 DPI 显示器后复查；小屏下双向滚动三个页面并按 Tab 切换控件，侧栏应保持固定、工作区不得覆盖品牌，被裁剪控件应能随键盘焦点滚回可见区。
3. 连续拖动光圈半径 8→100，尤其检查 36→37→60→100；线宽在合法范围内逐步变化，不透明度 10→100。示例应在拖动过程中变化，不能等松手才刷新，也不能在大数值区间停止变化。
4. 高亮模式检查半径 8→100、不透明度 10→50；选择图片/GIF 后检查半尺寸 8→256、不透明度 10→100。尺寸全范围持续变化、图片比例正确，图形不覆盖标题或底部信息条。
5. 先清空保持时长，再拖动三个滑块：示例仍同步，错误输入保留且无法保存。修正输入后保存；另做一次修改后取消，确认恢复原设置。半径缩至 8 时线宽仍须小于半径两倍。
