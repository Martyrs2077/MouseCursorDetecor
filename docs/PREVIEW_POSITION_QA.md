# 预览指针与每素材位置

2026-11-05。用户已确认在 MouseCursorDetector 中保留现有排版，预览固定显示当前系统正在使用的指针图样，拖动图片/GIF 记录相对位置，每素材分别保存，保存配置成功后正式应用，重新打开时恢复。

## 实现

- 主设置与素材库预览均读取当前全局指针句柄，按真实热点固定在舞台中心；替换原主舞台手绘箭头。彩色指针读取颜色位图尺寸，单色指针按双高掩码折算。借用句柄不销毁，`GetIconInfo()` 创建的位图成对释放。
- 图片与指针使用同一预览比例。图片中心相对指针热点的偏移按 DIP 记录，右/下为正；实际窗口按显示器 DPI 换算后使用同方向偏移。指针源位图按当前指针所在显示器 DPI 换算，支持预览与真实鼠标位于不同缩放显示器的情况，仍需人工复核。
- 主预览和素材页通过原生 STATIC 子类转接按下、移动、松开及捕获丢失；捕获期间拖出控件继续处理，改变大小、隐藏或销毁控件时停止拖动。拖动图片含透明像素，也允许从舞台空白拖动，以便找回偏移素材。图片中心限制在舞台内，DIP 偏移限制 ±512；移至边缘时超出部分在预览中裁切，正式素材不裁切。
- 拖动只改 `draft_.image_offsets`，按区分大小写的素材名称分别记忆；切换、取消和保存复用现有草稿快照流程。素材页静态图也显式失效并即时重绘，GIF 保持原有播放流程。
- 偏移独立于 `UserStyle` 和 `library.json`。刷新及导入仍即时登记素材，但不会提交或覆盖尚未保存的位置。保存失败时保留编辑，正式提示不切换。
- `settings.json` 更新为版本 4，兼容版本 1/2/3，旧配置零偏移。平面字段 `image_offset_count`、`image_offset_N_name`、`image_offset_N_x`、`image_offset_N_y` 最多 512 条；x/y 为 DIP 加 512 的无符号编码，范围 0–1024，缺少条目为零偏移。校验名称、重复条目、类型、计数及坐标；只保存当前库中存在的素材位置，配置仍原子替换。
- `NativeCursorWindow::ApplyStyle()` 在钩子线程查表并缓存物理像素偏移；鼠标回调调用的 `FollowCursor()` 只给窗口位置加缓存值，不查表、不读文件、不绘图。内置光圈和高亮保持中心定位。
- 未调用改变系统指针的 API，未改变线程所有权、快捷键、保持时长、自启动和素材命名规则，没有新增源文件或运行时依赖。

## 用户手动构建和验收

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

- [ ] 四套主题及 100%/125%/150%/200% 缩放中，两个预览区都显示当前系统指针图样，热点位置固定；分别用普通、放大、彩色及非左上热点指针核对。跨不同 DPI 显示器后重查比例。
- [ ] 在主预览与素材页分别拖动静态 PNG 和 GIF 到四个方向，连续移动即时刷新，透明边缘可拖，指针不随图片移动；拖出控件松开、Alt+Tab、调整窗口大小后不会继续黏住图片。
- [ ] 给素材 A/B 设置不同位置，反复切换恢复各自草稿；刷新及导入第三个素材不丢失 A/B 编辑，也不提前改变快捷键触发的正式提示。
- [ ] 保存成功后触发提示，核对图片中心相对真实指针热点的方向与距离；重新打开设置及重启后仍恢复，GIF 各帧位置不跳动。
- [ ] 素材页取消恢复进入前的位置；主设置取消恢复已保存位置；保存路径不可写时报告失败并保留编辑，实际提示及旧配置保持原值。
- [ ] 用旧版本配置检查默认居中；检查负偏移、零偏移和边界位置，素材靠近舞台边缘时仅预览裁切，正式图像完整。内置光圈/高亮仍居中，真实系统指针始终保持原样。

当前预览对动画系统指针绘制第 0 帧作为静态参照，不承诺复现系统指针动画、动态反色的桌面背景或像素级一致的缩放采样；GIF 素材动画保持原逻辑。
