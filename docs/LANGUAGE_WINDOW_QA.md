## 已实现的约定

- 右上角不再绘制逗号、句号和加号键帽。实际快捷键录入框、绑定、触发和保持时长仍沿用原入口。
- 提示设置的半径、线宽、不透明度、保持时长与快捷键 EDIT 直接复用素材库“导入新素材”的 `PrepareField()`，左对齐、10pt Microsoft YaHei UI、31 DIP 高。四个数值框宽 56 DIP，保留数字限制、校验和原有滑块/单位顺序；快捷键继续使用 `HotkeyProc()`。共用输入框绘制代码未修改，当前样式下拉框继续复用相同表面及原生选择行为。
- 设置窗口具有 `WS_EX_APPWINDOW`：打开显示任务栏按钮；最小化交给系统处理，保留任务栏和托盘；点击关闭执行 `SW_HIDE`，移除任务栏按钮并保留当前页面、输入与草稿。取消主设置继续调用 `Close()`，恢复最近保存的设置并销毁窗口。托盘打开及重复启动会恢复最小化窗口。
- 关闭或最小化期间，素材后台任务可以完成；设置恢复显示后才处理命名或错误对话框。预览重绘定时器在隐藏或最小化时不重绘 GIF 示例；提示层的运行逻辑保持原样。
- 三页右上角固定显示 `Language/语言`。按钮与保存设置使用同一个 `PrepareButton()` / `Button(primary=true)`。素材库为独立子窗口，因此在该页创建同款按钮并调用同一个 `ToggleLanguage()`，主窗按钮在该页隐藏。
- 默认中文；点击即时切换应用界面、托盘菜单、通知、关于、素材命名及应用错误说明。164 组中英文文案内嵌 EXE。语言仅随主设置“保存设置”提交，取消恢复最近保存的语言，“恢复默认”将语言草稿重置为中文；关闭到托盘保留当前语言草稿。“保存样式”仍仅保存素材库。
- `RefreshLanguage()` 更新文案、内置选项和绘制，不调用 `ReadControls()` / `LoadControls()` / `CreateControls()` 或写数值的接口；未完成数字输入、错误边框、路径、素材名称、当前选择和页面不会因语言切换被重建。

## 配置兼容与系统边界

新增可选无符号 `ui_language`：0 中文、1 英文；缺失、错误类型或越界时回退中文。配置仍为平面 JSON 版本 2，并继续兼容版本 1；旧注册表二进制记录布局、默认提示参数、路径规则及原子保存实现不变。示例更新于 `docs/settings.example.json`，未读取或修改用户的 `config/settings.json`。

后台解码/导入及配置加载继续产生原有诊断文本，UI 显示时翻译，不改写素材业务。用户自定义名称、路径和第三方许可原文保持原样。文件/颜色选择对话框、系统错误描述、系统按钮和键名由 Windows 提供，随系统语言及可用语言资源决定；安装包和项目文档不加入英文切换。

## 用户手动构建与验收

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

1. 打开设置有任务栏按钮与托盘；最小化保留两者；点击关闭仅保留托盘；从任务栏、托盘及再次双击 EXE 恢复，页面和未保存输入一致，无重复窗口。
2. 将数字框临时清空，切换语言两次：空值和错误边框仍在，其他未保存数值、滑块位置及素材路径不丢失。输入 3600，检查四位数字、插入点和选中背景完整。
3. 三个页面右上角按钮始终为 `Language/语言`，四主题下与保存设置的常态、悬停、按下、焦点及禁用样式一致；右上角没有快捷键键帽。
4. 中英文各检查主设置、主题名称、素材导入/命名、托盘菜单、关于、校验与失败提示；自定义名称恰为“素材库”或“光圈提示”时也保持原名。
5. 切换语言后先关闭再打开，草稿仍在；取消后恢复已保存语言。保存设置后退出重启恢复语言；配置不可写时保持草稿并报告失败。只保存素材库后退出重启，语言仍为此前保存值。
6. 在导入中切换语言、最小化或关闭至托盘，完成后不应弹出打断窗口；恢复设置后命名/错误提示使用当前语言。取消素材页不丢失独立的语言草稿。
7. 四主题以及 100% / 125% / 150% / 200% 和混合 DPI 屏幕下，输入框外观与素材路径框一致，正文、控件、滑块、单位和中英文状态均无裁切或重叠；Tab、Shift+Tab、Enter、Space、IME、复制粘贴及快捷键录入保持可用。
