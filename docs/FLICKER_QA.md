# 设置窗口闪烁与边框一致性

## 2026-11-04 焦点工作台回归修复

用户报告点击「提示设置 / 素材库 / 外观主题」及调整参数时闪烁，截图中的快捷键输入框还出现矩形边缘。用户确认：保留布局、四套主题及白底圆角输入样式，修复绘制问题。

### 本轮源码调整

- `settings_ui.h` 增加作用域重绘批处理，覆盖页面切换、布局、控件装载与主题变更；嵌套更新由最外层恢复重绘。初始隐藏窗口不发送 `WM_SETREDRAW(TRUE)`，避免意外显示；状态检查失败时保持原绘制路径。
- 素材页创建与最终布局在同一批次完成；离开素材库直接进入目标页，取消时仍恢复进入前的草稿与提示效果，不先显示主设置页。素材导入中的导航限制与独立保存语义保留。
- 四主题结构一致，`ApplyTheme()` 不再触发布局。模式变更及装载设置仍显式布局；滑块仅在范围或数值改变时同步，拖动时只主动失效当前滑块，避免所有滑块反复刷新。
- 主窗口、素材页背景及自绘按钮、滑块、收起下拉框使用完整内存绘制后上传，最终 `BitBlt` 遵守目标 DC 的更新区域与子窗口裁剪。图片/GIF 预览沿用已有缓冲，不额外增加缓冲层。
- 输入框外框使用同样的内存缓冲，通过排除客户区的目标 DC 上传；合成 `WM_PRINT` 分别处理自绘外框与原生 `WM_PRINTCLIENT`，按真实客户区偏移并裁剪正文，避免原生打印再次覆盖矩形外框。非客户区激活也进入统一重绘路径。
- 输入框白底、圆角、普通/悬停/焦点/错误/禁用颜色、客户区边距及控件尺寸均沿用现行设计。快捷键、数值、素材路径及命名输入框共用此修复。

### 静态复核与验证边界

- 静态核对重绘作用域的嵌套、隐藏状态、早返回、GDI 对象恢复与释放、打印坐标与裁剪，以及主设置、素材库、主题页导航和模式切换的布局覆盖。
- 六个修改过的 C++ 文件已通过改动范围的 Google clang-format 检查，差异空白检查通过（按原文件 CRLF/LF 处理）。源码检索未发现 `SetSystemCursor`、`SetCursor`、`ShowCursor` 调用。
- 未修改系统鼠标光标、钩子线程、配置格式、默认值、构建依赖或用户运行数据。
- 尚未编译、尚未运行验证。静态复核不能证明真实 Win32 窗口已无闪烁，也不能替代原生 EDIT、合成绘制、DPI、IME 与焦点的交互验收。

### 用户手动构建后验收

1. 在项目根目录执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1`，或双击 `build.cmd`。
2. 四主题下反复按「提示设置 → 素材库 → 外观主题 → 提示设置」，特别检查素材库直接切到主题页时无主设置中间帧；鼠标悬停、键盘导航及选中状态正确。
3. 连续拖动半径、线宽、不透明度，直接编辑数字及保持时长，切换光圈/高亮和颜色；检查背景、预览、输入框无闪白、闪暗、残影。
4. 检查快捷键、数字、路径、命名输入框和收起下拉框的普通、悬停、聚焦、错误及禁用状态，均无黑色方框、双边框或正文被外框覆盖；切换前后台、最小化后重新打开亦正常。
5. 100% / 150% / 200% 缩放及跨屏后复查圆角、文本、滚动与焦点；使用 Tab、Shift+Tab、Enter、Space、F4/Alt+下箭头、粘贴与中文输入。导入图片/GIF 后分别保存和取消，核对原有素材与草稿行为。

## 2026-11-03 初轮处理

2026-11-03。用户确认 `design-previews/2026-11-03-border-consistency/` 中的边框预览后实施；四套主题沿用现有配色与布局。

## 原因与源码修改

- 滚轮在不可滚动、已到边界或增量不足一格时仍调用完整布局；现在钳制后的滚动位置不变就返回。
- 每次布局先显示页面全部控件，再逐主题隐藏部分控件；现在一次求出最终可见性，仅在状态变化时显隐。
- 控件位置及布局标题未变化也会重新设置；现在几何与文本不变时跳过。布局增加重入保护，防止滚动条更新引发嵌套布局。
- 主窗、素材页分别擦除背景再绘面板，主题应用还请求全体子控件擦除；现在背景并入完整绘制，主窗采用 `WS_EX_COMPOSITED`，普通失效不请求擦除。仅主题真正变化时刷新整棵控件树。
- 圆角按钮、主题卡片与导航每次先铺满自身矩形，避免取消擦除后留下旧圆角与抗锯齿像素。
- 所有外边框共用 `BorderWidth(HWND)`：返回目标窗口 DPI / 96，保留 150% 下的 1.5 像素线宽。笔画中心向内偏移半个线宽，防止边框裁切。
- 编辑框使用自绘非客户边框；下拉框只接管收起外观，保留原生列表、消息与选择操作。素材路径及命名弹窗输入框一并覆盖。焦点提示独立于外边框。

## 已执行的检查

- 静态对照四套主题、光圈与非光圈以及三个页面的显隐条件，保留原有最终显示规则；未调整控件布局坐标。
- 独立只读审查窗口消息、子类链、DPI、GDI 资源及布局路径。发现并修正 `WM_PRINT` 对可见性和 `PRF_CLIENT` 标志的处理。
- 使用 Windows 的 System.Drawing 测量最窄数值框（50×28 DIP，边框及内边距后 42×20 DIP）的四位数字和行高。Microsoft YaHei UI 与 Consolas 的 10pt 字体在 96 / 120 / 144 / 192 DPI 共 8 组检查均能容纳。
- 对修改范围执行 Google 预设的 clang-format 格式检查；检查新头文件、边框调用及资源配置。检查仅涉及静态文本和格式，不调用编译器。
