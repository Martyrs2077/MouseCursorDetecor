# 自定义图片与 GIF 使用说明

2026-11-02：源码实现已接入；助手未配置构建、编译或运行软件，以下操作需用户手动构建后验收。

## 目录和使用

```text
MouseCursorDetector/
  MouseCursorDetector.exe
  config/
    settings.json
  styles/
    自动生成的独立文件名.png
    自动生成的独立文件名.gif
```

所有路径以 EXE 所在目录为基准，不以终端工作目录或源代码目录为基准。当前手动构建将便携 EXE 发布到项目根目录，因此配置和素材位于项目根目录的 config 和 styles；安装版则位于安装目录旁。旧版 dist 中的数据保留，但不自动迁移；直接运行 build/gcc-release 中的 EXE 时，配置仍位于该构建目录旁。

1. 手动构建后打开软件，在托盘菜单选择“打开设置菜单”。
2. 在顶部点击“素材导入”，在导入页面点击“浏览文件”选择图片/GIF，或在路径框粘贴文件完整路径（兼容两端双引号）。
3. 点击“导入素材”。软件在后台复制和解码，导入期间仍监听键盘，失败时保留原样式。不要通过原路径修改已导入素材；重新导入才会更新缓存。
4. 素材验证成功后弹出命名窗口。输入自定义名称，或留空点击“确定”，使用原文件名（含扩展名）。名称去除首尾空白，最多 255 个 UTF-16 字符，不允许控制字符。名称严格区分大小写：`Halo.png` 与 `halo.png` 不重名，两个 `Halo.png` 重名。重名时显示错误并保留命名窗口，必须换一个可用名称才能完成导入，也可取消本次导入。取消命名会尝试删除本次新复制的临时素材，不影响原文件和历史样式。
5. 完成命名后先在导入页面预览；点击导入页面“保存”成功写入样式库后，名称才加入主设置“光圈样式”下拉列表并自动选中。导入页面显示导入状态、尺寸/帧数和透明棋盘格预览；GIF 循环预览，静态图片保持宽高比。导入页面点击“取消”恢复进入前的选择和样式库；已完成命名的文件仍保留。导入页面保存只提交样式库，主设置中的其他未保存修改仍需点击主窗口“保存设置”。可反复导入并切换历史样式，无需重新输入路径。选中 GIF 样式自动播放动画，选中图片样式显示静态图。可调整半尺寸与整体不透明度。最长边为半尺寸两倍，宽高比保持不变，素材中心对齐光标热点。
6. 按“， + 。”可在当前提示时段内查看所选样式；GIF 每次触发从首帧开始，按帧延时循环，到指定时长隐藏。文件自身循环次数不限制提示期间的循环。所选 GIF 样式会播放动画。
7. 点击主设置窗口的“保存设置”，将当前选择、外观参数、快捷键和保持时长写入 JSON。取消主设置恢复之前的选择，但已在导入页面保存的样式库仍然保留。“恢复默认”重置参数与当前选择，保留样式库。
8. 退出软件并重新打开，样式列表、名称和当前选择恢复；提示初始隐藏，监听自动运行。删除最初导入的原文件不影响已复制素材。

要迁移到其他电脑，复制 EXE、config、styles 整个目录。软件目录需要有写入权限；写入失败会报告原因，保存失败保留旧配置。开机自启动属于当前用户的系统设置，不能通过复制文件夹迁移，需要在新电脑重新勾选。

## 设置界面

主设置按“提示外观 / 触发方式 / 系统”三张卡片分组，左侧固定导航切换提示设置、素材库和外观主题。所有数值输入框只显示数字：半径、素材半尺寸和线宽的 DIP，不透明度的 %，显示时长的“秒”，均以独立标签显示在输入框右侧。数值框与滑块双向联动，范围沿用原设置；光圈模式才显示线宽行。快捷键输入框显示当前按键，默认“， + 。”，点击即可重新录制。

当前设计见 [DESIGN.md](../DESIGN.md)，四套主题的可视化预览位于 design-previews/2026-11-03-settings-redesign/index.html。源码基准客户区为 900 × 720 DIP，最小内容区为 820 × 720 DIP，支持 DPI 缩放及空间不足时的双向滚动。设计预览与旧 settings-ui-reference.svg 仅供参考。本次源码尚未编译运行，不能将预览当成 EXE 截图。

素材预览仅用于查看文件内容，按预览区域适配大小，并保留原透明度；实际提示尺寸和整体不透明度仍由主设置控制。导入/加载期间禁止再次提交、切页或取消任务；主窗口关闭可隐藏至托盘，最小化保留任务栏。后台任务完成后等待设置恢复显示才弹出命名或错误窗口。开机自启动复选框仍立即生效，只负责登录后启动软件，不会在启动时显示高亮。

## 格式与边界

- 基础读取使用 Windows WIC：PNG、JPG/JPEG、BMP、TIFF/TIF、ICO、GIF 等。WebP、HEIC/HEIF、AVIF 等依赖本机实际可用的 WIC 解码器，失败会提示；尚未承诺动态 WebP/APNG 动画或 SVG、PSD、RAW 的完整支持。
- PNG 等素材自身的透明像素予以保留，整体透明度再乘以原 Alpha。没有透明信息的图片仍显示矩形底色，不自动抠图。
- TIFF 等非 GIF 多帧格式仅取第一页；ICO 优先选择接近 256 像素的合适尺寸。
- 单文件不超过 20 MiB；静态图宽高各不超过 4096，缓存最长边最多 512 像素。
- GIF 宽高各不超过 1024、最多 200 原始帧；画布宽×高×帧数不超过 64 Mi 像素；合成帧缓存不超过 64 MiB，最长边最多 256 像素。
- GIF 处理透明色、局部帧及 disposal 2/3；零延时中间帧参与合成但不单独显示。非零延时限制为 20–60000 ms，动画定时器约 20 ms 检查一次，不承诺精确逐毫秒呈现。
- MP4 不在本轮功能范围内，评估见 CUSTOM_STYLE_FEASIBILITY.md。

## 配置行为

JSON 使用版本 2 的平面对象，兼容读取版本 1。值为无符号整数或字符串，不接受注释、重复字段、数组和嵌套对象。style_file 形如 `styles/唯一文件名.gif`，不接受绝对路径、父目录跳转或嵌套目录。配置允许中文；样式显示名称与磁盘文件名分开保存，磁盘使用唯一文件名避免覆盖，大小写不同的显示名称不会造成存储冲突。style_count 保存样式数量；style_0_name / style_0_file、style_1_name / style_1_file 等字段保存各样式的名称和相对路径。样式库最多 512 项，配置文件不超过 2 MiB。区分大小写的重名检查同时用于导入、配置读取与保存，手动写入完全同名的配置会被视为无效配置。

可选字段 `ui_language`：0 中文（默认），1 英文；缺失、类型不符或越界归一为中文。右上角 `Language/语言` 即时切换，但只有主设置“保存设置”成功才提交语言；素材页“保存样式”只提交素材库，不连带保存语言、主题或其他草稿。中英文文案内嵌 EXE，无需旁置语言文件。

旧版配置只有一个已选素材路径，没有原文件名；升级时用已保存素材的文件名作为该样式的显示名称补入列表。只加载当前素材的图像缓存，其他样式切换时后台加载；加载失败保留原选择，不重复导入或再次弹出命名窗口。

完整默认字段示例见 settings.example.json，仅用于文档，不会自动覆盖软件当前配置。mode 为 0 高亮、1 光圈、2 静态图片、3 GIF 动画；素材类型和相对路径由软件导入后填写。

默认配置使用内置光圈，`style_file` 为空、`style_count` 为 0。内置光圈和高亮通过 GDI+ 绘制，无需外部素材文件；源码仓库包含默认图标及全部构建资源，因此没有 `styles/` 也能使用默认提示。`styles/` 仅在导入自定义图片或 GIF 后需要，迁移自定义配置时必须同时携带其中被配置引用的文件。

JSON 不存在时尝试迁移旧注册表设置，保留原快捷键、模式与时长；首次运行使用默认设置并创建 JSON。JSON 已存在时不再用注册表覆盖。配置损坏时使用默认值并提示，不自动覆盖损坏文件；可以在设置中确认后重新保存。

采用同目录临时文件写入、刷新后替换 settings.json；失败不主动删除旧配置。自启动仍使用 HKCU Run，提示显示状态不持久化。

素材缺失、格式不支持或解码失败时，选中自定义模式会回退到内置光圈并提示；原素材路径可用于定位问题。删除 styles 中的文件前应确认未被当前配置引用。当前不自动清理取消导入或历史素材。

## 用户手动构建后的验收

- [ ] 主设置分组、底部按钮完整可见；100% / 150% / 200% 缩放下输入框、外部单位和滑块不重叠；数值框只显示数字。
- [ ] 输入数值和拖动滑块均能同步，半径/透明度范围按模式变化；光圈线宽行仅在光圈模式显示，时长支持输入 1–3600。
- [ ] 无素材时下拉列表仅显示两个内置样式，各模式下“导入光圈样式”均可点击；导入并命名后在导入页面保存之前，名称不会出现在下拉列表。
- [ ] 导入页面预览透明 PNG、GIF 动画正常；点击素材页取消恢复之前的选择和提示效果；主窗口关闭隐藏至托盘并保留页面，主设置取消则恢复已保存设置。

- [ ] 从含中文和空格的目录导入透明 PNG、JPG、BMP、TIFF、ICO，正常显示且不改变系统光标。
- [ ] 输入带双引号的文件路径，验证成功后弹出命名窗口；留空确定使用原文件名（含扩展名），输入名称后上方列表显示该名称。
- [ ] 再次导入同名文件，留空确定提示重名且窗口保持打开；输入完全相同名称、首尾带空格的同名名称不能通过，改用不同名称才成功。
- [ ] `Halo.png` 和 `halo.png` 可以分别导入、保存、重启后切换，分别显示各自素材；完全相同名称在重启后仍被拒绝。
- [ ] 同一源文件可以用不同名称导入；磁盘文件独立保存，不覆盖旧素材；取消命名不增加列表项、不改变当前选择。
- [ ] 连续导入多个图片/GIF，导入页面保存后可在列表切换；保存失败不新增列表项；主设置取消后已保存的样式仍存在，重启后仍可选择。
- [ ] 导入后点击确定，删除原文件，重启后选择和素材仍恢复。
- [ ] 从另一个工作目录启动 EXE，仍读取其自身目录旁的 config/styles。
- [ ] 复制整个目录到新路径运行，素材可读；自启动的旧路径可修正。
- [ ] GIF 带透明背景、局部帧、disposal 2/3 时无明显残影；长按不重复触发，再次触发从首帧重新计时；3 秒或自定义时长到期后隐藏并继续监听。
- [ ] 导入错误文件、MP4、超大图和超多帧 GIF 时报告失败，旧选择和配置仍可用。
- [ ] 取消主设置恢复旧模式并保留已保存的样式库；恢复默认清除自定义选择但保留样式列表、不删除素材。
- [ ] 手动移走已选 styles 文件或损坏 JSON，重启后出现提示且可继续使用默认光圈。
- [ ] 目录不可写或配置被其他程序独占时保存失败，旧配置未被破坏。
- [ ] 动画期间跨 DPI、多屏、锁屏、休眠、重复触发、退出无明显延迟及持续资源增长。
- [ ] 更新 EXE 的构建脚本保留已有 config/styles；没有运行时动态 GCC 或第三方 DLL 依赖。
