# 自定义图片与 GIF 使用说明

2026-11-05：源码已调整为独立映射表、目录刷新、真实缩略图列表和保存后应用。本次尚未编译、尚未运行验证，以下新行为需用户手动构建后验收。

## 目录和使用

```text
MouseCursorDetector/
  MouseCursorDetector.exe
  config/
    settings.json
  styles/
    library.json
    原始文件名.png
    原始文件名_1.png
    动画.gif
```

所有路径以 EXE 所在目录为基准，不以终端工作目录或源代码目录为基准。当前手动构建将便携 EXE 发布到项目根目录，因此配置和素材位于项目根目录的 config 和 styles；安装版则位于安装目录旁。旧版 dist 中的数据保留，但不自动迁移；直接运行 build/gcc-release 中的 EXE 时，配置仍位于该构建目录旁。

1. 手动构建后打开软件，在托盘菜单选择“打开设置菜单”。
2. 点击左侧“素材库”自动刷新。导入按钮前的“刷新”执行同样操作：读取映射表、核对各文件、移除明确已删除的记录，并登记目录内尚未映射的有效图片/GIF；不递归读取子目录，忽略映射表、临时文件和非支持扩展名。访问失败保留记录，显示不可用，不误当作删除。
3. 点击“浏览”选择图片/GIF，或粘贴完整路径（兼容两端双引号），然后点击“导入素材”。复制与解码在后台执行，不阻塞键盘监听。文件复制到 EXE 旁的 styles/，保留原文件名；磁盘或映射中已使用该路径时，按 `name_1.png`、`name_2.png` 递增，绝不覆盖原文件。
4. 验证成功后仍使用命名窗口。名称留空取原文件名；去除首尾空白，最多 255 个 UTF-16 字符，不允许控制字符，完全同名不允许，大小写不同可以共存。显示名称与磁盘文件名独立：两者无需相同。取消命名只尝试删除本次新复制的文件，不影响源文件或历史素材。
5. 命名成功即更新素材映射，右侧“素材列表”展示所有已登记素材。每项显示等比例真实缩略图、名称及类型，GIF 固定首帧；单击或用方向键选择即后台加载对应素材，在左侧预览。大预览保持宽高比与源透明度，按实际尺寸和不透明度等比显示；固定绘制当前系统指针作为参照，可拖动图片调整相对位置，移至边缘时超出预览区域的部分会裁切；GIF 按完整帧序列及帧延时循环。缩略图最长边 96 像素，仅一帧，不为列表缓存整段动画。
6. 素材选择、位置、模式和参数调整仅影响设置窗口内预览，快捷键触发仍使用最近保存的正式配置。点击素材页“保存配置”或主设置“保存设置”成功后，才将当前草稿、素材选择、主题、语言、快捷键和时长正式应用。保存失败保持窗口及编辑，报告原因。
7. 素材页“取消”或切到其他页面恢复进入前的素材选择；已经命名登记或刷新发现的素材库记录保留。被确认删除的记录不会因取消恢复。取消主设置撤销未保存配置；“恢复默认”保留素材库和文件。关闭主窗口隐藏到托盘并保留页面及草稿。
8. 正式使用的素材在刷新时被确认删除，立即回退默认绿色光圈（36 DIP 半径、7 DIP 线宽、90% 不透明度、3 秒保持），自定义外观数值也恢复默认；保留快捷键、界面主题及语言。即使当前正在预览另一素材，也不会顺带提交该未保存选择。无法写入配置时报告失败，并停止显示已删除的缓存素材；磁盘回退须在恢复写入后重新保存。
9. 提示每次触发从 GIF 首帧开始，到已保存时长后隐藏。删除最初导入的源文件不影响 styles/ 副本。要更新素材文件内容，点击刷新重新读取缓存。

要迁移到其他电脑，复制 EXE、config、styles 整个目录。软件目录需要有写入权限；写入失败会报告原因，保存失败保留旧配置。开机自启动属于当前用户的系统设置，不能通过复制文件夹迁移，需要在新电脑重新勾选。

## 设置界面

主设置按“提示外观 / 触发方式 / 系统”三张卡片分组，左侧固定导航切换提示设置、素材库和外观主题。所有数值输入框只显示数字：半径、素材半尺寸和线宽的 DIP，不透明度的 %，显示时长的“秒”，均以独立标签显示在输入框右侧。数值框与滑块双向联动，范围沿用原设置；光圈模式才显示线宽行。快捷键输入框显示当前按键，默认“， + 。”，点击即可重新录制。

当前设计见 [DESIGN.md](../DESIGN.md)，四套主题的可视化预览位于 design-previews/2026-11-03-settings-redesign/index.html。源码基准客户区为 900 × 720 DIP，最小内容区为 820 × 720 DIP，支持 DPI 缩放及空间不足时的双向滚动。设计预览与旧 settings-ui-reference.svg 仅供参考。本次源码尚未编译运行，不能将预览当成 EXE 截图。

素材预览使用主设置的尺寸及整体不透明度，与固定指针按相同比例缩放。指针热点保持在预览中心，拖动调整图片中心相对热点的水平、垂直偏移；每素材独立记忆，切换素材恢复各自草稿位置。拖动只改变预览，保存成功后正式提示采用相同 DIP 偏移，重新打开及重启恢复已保存位置。图片中心限制在舞台内且偏移不超过 ±512 DIP，避免拖到无法找回；可拖动透明像素或舞台空白找回已偏移图片。取消恢复进入前的位置，刷新及导入不提交位置。真实系统指针始终由 Windows 管理。导入/加载期间禁止再次提交、切页或取消任务；主窗口关闭可隐藏至托盘，最小化保留任务栏。后台任务完成后等待设置恢复显示才弹出命名或错误窗口。开机自启动复选框仍立即生效，只负责登录后启动软件，不会在启动时显示高亮。

## 格式与边界

- 基础读取使用 Windows WIC：PNG、JPG/JPEG、BMP、TIFF/TIF、ICO、GIF 等。WebP、HEIC/HEIF、AVIF 等依赖本机实际可用的 WIC 解码器，失败会提示；尚未承诺动态 WebP/APNG 动画或 SVG、PSD、RAW 的完整支持。
- PNG 等素材自身的透明像素予以保留，整体透明度再乘以原 Alpha。没有透明信息的图片仍显示矩形底色，不自动抠图。
- TIFF 等非 GIF 多帧格式仅取第一页；ICO 优先选择接近 256 像素的合适尺寸。
- 单文件不超过 20 MiB；静态图宽高各不超过 4096，缓存最长边最多 512 像素。
- GIF 宽高各不超过 1024、最多 200 原始帧；画布宽×高×帧数不超过 64 Mi 像素；合成帧缓存不超过 64 MiB，最长边最多 256 像素。
- GIF 处理透明色、局部帧及 disposal 2/3；零延时中间帧参与合成但不单独显示。非零延时限制为 20–60000 ms，动画定时器约 20 ms 检查一次，不承诺精确逐毫秒呈现。
- MP4 不在本轮功能范围内，评估见 CUSTOM_STYLE_FEASIBILITY.md。

## 配置行为

普通配置使用版本 4 的平面 JSON，兼容版本 1/2/3，单文件最多 2 MiB，值仅为无符号整数或字符串，不接受注释、重复字段、数组或嵌套对象。配置用 `style_name` 保存所选素材名称，另以 `image_offset_count` 和 `image_offset_N_name/x/y`（实际键名为 `image_offset_N_name`、`image_offset_N_x`、`image_offset_N_y`）保存每素材位置，不保存素材路径和库映射。坐标为图片中心相对系统指针热点的 DIP 偏移，右/下为正，允许 −512–512；磁盘 x/y 使用“偏移 + 512”的无符号编码（0/512/1024 分别为 −512/0/+512）。最多 512 条记录，名称区分大小写、不可重复，缺少记录默认为零；旧配置缺省零偏移。类型、坐标或计数非法时按损坏配置处理，保留原文件。示例见 [settings.example.json](settings.example.json)。

`styles/library.json` 是唯一持久化的名称到文件映射，格式为版本 1 的平面 JSON：`style_count`、`style_N_name`、`style_N_file`；空库示例见 [library.example.json](library.example.json)。文件值为 `styles/文件名.ext`，拒绝绝对路径、父目录跳转和嵌套目录，同一受管文件不能重复登记，最多 512 项。名称比较严格区分大小写，Windows 文件路径比较不区分大小写。所有已导入文件的加载和缩略图读取都由 `LoadMappedStyle()` 先从当前映射解析名称，未映射文件只有在刷新验证并登记后才进入列表。

版本 1/2 配置只在 library.json 不存在时提供迁移种子；已有映射表始终优先。旧素材不改名，旧配置在下次保存配置时升级为版本 4 并去除重复映射；进入素材库可先建立唯一权威映射。刷新和完成导入命名独立保存映射，不提交当前所选素材及参数。刷新发现未映射文件时使用文件名作为显示名称，若显示名称已占用则在扩展名前加 `_1`、`_2`；不会为目录内现有文件改名。

配置和映射表各自通过同目录临时文件写入、刷新并替换，失败保留该文件旧内容。保存配置先更新映射，再更新配置；这不是跨文件事务，配置写入失败时，已完成的库登记仍然保留，但正式选择与参数不切换。损坏或无法读取的映射表不被自动覆盖，刷新报告错误并保留当前列表。配置损坏继续报告并使用默认设置，不在加载时覆盖。

`ui_language` 为 0 中文（默认）、1 英文，缺失或非法时归一为中文；中英文内嵌 EXE。映射维护不改变语言；素材页“保存配置”与主设置“保存设置”均保存整个草稿。没有 JSON 时仍只读迁移旧注册表，旧记录不回写；自启动仍使用 HKCU Run，提示显隐不持久化。

默认 `style_name` 为空、映射 `style_count` 为 0。内置光圈和高亮由程序绘制，无需外部素材；复制自定义配置时要同时携带 styles/ 中的映射表和图片。源素材透明度被保留，正式提示大小和不透明度由已保存配置控制。

## 用户手动构建后的验收

- [ ] 主设置分组、底部按钮完整可见；100% / 150% / 200% 缩放下输入框、外部单位和滑块不重叠；数值框只显示数字。
- [ ] 输入数值和拖动滑块均能同步，半径/透明度范围按模式变化；光圈线宽行仅在光圈模式显示，时长支持输入 1–3600。
- [ ] 无素材时下拉列表仅显示两个内置样式，各模式下“导入光圈样式”均可点击；导入命名后列表立即可选，选择只更新窗口预览，保存配置后实际提示才变化。
- [ ] 导入页面预览透明 PNG、GIF 动画正常；点击素材页取消恢复之前的选择和提示效果；主窗口关闭隐藏至托盘并保留页面，主设置取消则恢复已保存设置。

- [ ] 从含中文和空格的目录导入透明 PNG、JPG、BMP、TIFF、ICO，正常显示且不改变系统光标。
- [ ] 输入带双引号的文件路径，验证成功后弹出命名窗口；留空确定使用原文件名（含扩展名），输入名称后上方列表显示该名称。
- [ ] 再次导入同名文件，留空确定提示重名且窗口保持打开；输入完全相同名称、首尾带空格的同名名称不能通过，改用不同名称才成功。
- [ ] `Halo.png` 和 `halo.png` 可以分别导入、保存、重启后切换，分别显示各自素材；完全相同名称在重启后仍被拒绝。
- [ ] 同一源文件可以用不同名称导入；磁盘文件独立保存，不覆盖旧素材；取消命名不增加列表项、不改变当前选择。
- [ ] 连续导入多个图片/GIF，可在素材列表逐项切换预览；映射保存失败不新增列表项；取消选择后已登记的素材仍存在，重启后仍可选择。
- [ ] 导入后点击确定，删除原文件，重启后选择和素材仍恢复。
- [ ] 从另一个工作目录启动 EXE，仍读取其自身目录旁的 config/styles。
- [ ] 复制整个目录到新路径运行，素材可读；自启动的旧路径可修正。
- [ ] GIF 带透明背景、局部帧、disposal 2/3 时无明显残影；长按不重复触发，再次触发从首帧重新计时；3 秒或自定义时长到期后隐藏并继续监听。
- [ ] 导入错误文件、MP4、超大图和超多帧 GIF 时报告失败，旧选择和配置仍可用。
- [ ] 取消主设置恢复旧模式并保留已保存的样式库；恢复默认清除自定义选择但保留样式列表、不删除素材。
- [ ] 手动移走已选 styles 文件或损坏 JSON，重启后出现提示且可继续使用默认光圈。
- [ ] 目录不可写或配置被其他程序独占时保存失败，旧配置未被破坏。
- [ ] 动画期间跨 DPI、多屏、锁屏、休眠、重复触发、退出无明显延迟及持续资源增长。
- [ ] 更新 EXE 的构建脚本保留已有 config/styles；没有运行时动态 GCC 或第三方 DLL 依赖。

完整的本轮静态核查与交互验收清单见 [MATERIAL_LIBRARY_QA.md](MATERIAL_LIBRARY_QA.md)。
