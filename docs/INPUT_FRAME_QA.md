# 输入框圆角与文字安全区

2026-11-05。用户提供素材路径输入框截图，要求矩形输入区域不破坏外观边框；确认缩短内部编辑区域、保留字体与高度，并允许数值框加宽以完整显示数字。

## 原因与显示层修改

`DrawFieldSurface()` 在窗口内缩 2 DIP 后绘制 8 DIP 圆角；此前原生 EDIT 客户区四边仅内缩 4 DIP，矩形客户区的四角进入圆弧。`PaintFieldFrame()` 排除该客户区后，圆弧相交段无法上传，原生编辑背景也会覆盖该位置。原生 `WS_BORDER` 与边缘扩展样式已经移除，重复移除不能解决几何重叠。

- `settings_control_frames.h`：共用 EDIT 客户区左右内缩改为 10 DIP，上下仍为 4 DIP；外框内缩与圆角半径共用常量。矩形编辑区域位于圆角弧线以内，不接管文字、选择或插入点绘制。小尺寸仍按各轴长度的一半钳制，避免客户区反转。
- `settings_themes.cc`：数值框宽度 40 → 56 DIP，右端和高度不变；左侧参数滑块缩短 16 DIP，原有控件顺序、单位与间隔不变。保持时长框也加宽为 56 DIP。
- 素材路径、样式名称及快捷键框外部尺寸不变。未改变字体、下拉框、边框状态、配置、参数范围或业务逻辑。

## 静态核查与验证边界

- 使用 Windows TextRenderer 按现有 10pt 字体对应的整数像素高度测量四位数字 `3600`，没有编译代码或启动程序。Microsoft YaHei UI 在 96 / 144 / 192 DPI 下宽度为 32 / 48 / 64 px；Consolas 为 28 / 44 / 60 px。56 DIP 控件扣除两侧 10 DIP 后，客户区为 36 / 54 / 72 px，保留现有字号时可容纳该数字；仍须实测原生 EDIT 内部边距、插入点与选择。
- 静态核对普通非客户区绘制与合成打印均读取真实客户区；横向尺寸调整不改变纵向文字空间。素材路径保持 31 DIP 高，数值保持 26 DIP 高，保持时长保持 30 DIP 高。

## 用户手动构建与验收

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

1. 四套主题下检查路径、名称、快捷键与数值输入框：普通、悬停、聚焦、错误、禁用时，圆角和单条边框连续，无矩形切口或双边框。
2. 100% / 150% / 200% 缩放及跨屏后检查原字号、完整 `3600`、三位数值与单位；滑块和数值框不重叠。
3. 输入长路径、长名称及中文，检查横向滚动、IME、全选、复制粘贴、Tab / Shift+Tab、快捷键捕获，以及原有导入和保存/取消行为。
