# 文字裁切修复记录

2026-11-03。保留四套主题、现有字号、配色及功能；按用户确认统一修正主设置、素材导入和主题选择页。

## 已定位的问题

- 44 DIP 高的双行外观按钮，副标题从 29 DIP 绘制到高度减 5，仅剩 10 DIP；本机 Microsoft YaHei UI 9pt 的实际行高在 100% 缩放下为 17 px。
- 暗色主题原外观按钮宽 102 DIP，扣除图标和边距后只剩 47 DIP；四字标题需要约 52 DIP，五字副标题需要约 60 DIP。
- 极简主题的当前样式与外观按钮共用一行，窄窗口时发生遮挡；暗色主题的参数标题与数值共用窄列。
- 清晰原生主题的预览标题、快捷键、显示时长控件边界存在交叠；长素材名换行后可能被固定高度截断。

## 源码调整

- 双行按钮统一 58 DIP 高；极简主题的当前样式单独成行；暗色参数分为标题、数值、滑块三行。
- 基准客户区改为 900×720 DIP，最小内容区为 820×720 DIP；空间不足时双向滚动，键盘焦点自动滚入视口。
- 调整原生主题控件间距、导入详情行高；长名称单行省略，悬停可读全文，`&` 按原文显示。
