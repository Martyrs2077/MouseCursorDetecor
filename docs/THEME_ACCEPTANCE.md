# 四主题手动验收

本次源码更新尚未编译或运行。按项目约定，由用户双击项目根目录 `build.cmd`，确认完整构建成功后使用新生成的 EXE 验收。

1. 新配置或旧配置没有 `ui_theme` 时默认“极简聚焦”；原光圈、快捷键和素材库保持原配置。顶部依次为“主设置 / 素材导入 / 主题选择”。
2. 主题页显示全部四套主题。逐个选择时立即改变配色及布局；返回主设置后，刚编辑的数值、颜色和当前样式仍在。主题卡的当前选择能通过文字和键盘识别。
3. 更改主题但不保存，点击取消或关闭；重新打开应恢复上次成功保存的主题。最小化再从托盘恢复，应保留未保存草稿。
4. 保存主题后，继续编辑再取消，应回到最近一次保存。退出程序并重启，仍使用保存的主题。保存失败应保留当前编辑，不能错误推进已保存快照。
5. 在主设置清空数值或输入越界值，切页或保存应显示错误并定位可见的输入框，不应在主题页针对隐藏字段报错。
6. 四主题中均可从顶部进入同窗口素材导入页；浏览、导入、命名、透明预览、GIF 动画、取消与保存样式正常。导入处理中不能切页；完成后恢复。
7. 先更改主题但不保存，再导入并“保存样式”，退出后检查：素材库保存成功，未保存的主题没有被提交。主设置“保存设置”才保存主题和当前素材选择。
8. 100% / 125% / 150% DPI、跨屏、较矮工作区及最大化下检查内容完整；从导入页 Tab/Shift+Tab 可回到顶部选项卡，底部按钮聚焦时自动滚入可视区域。Enter 保存当前页，Esc 取消当前页。
9. 四主题的“光圈提示 / 空心圆环”和“高亮光标 / 半透明底色”都完整显示。极简主题的“当前样式”独占一行，与外观按钮互不遮挡；暗色主题的半径、线宽、不透明度标题、数值、单位和滑块互不重叠。
10. 导入较长的中文名称及含 `&` 的名称；预览说明和素材状态应正确显示原文，过长时省略，悬停可看到完整名称。长路径和多键快捷键悬停可见全文；素材详情两行完整显示图片类型、像素和帧数。
11. 在 200% DPI 或较小工作区中，客户区不足 820×720 DIP 时出现相应滚动条；可以滚到右侧和底部，Tab 聚焦后目标控件完整可见。检查参数滑块拖动仍然正常，水平滚动不能改变参数值。

设计 HTML 的浏览器验证不代替以上 EXE 运行验收。
